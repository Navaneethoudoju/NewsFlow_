# AI prompts

I used AI mainly as a development helper during the project. Most of the
main application logic and workflow decisions were implemented based on the
assignment requirements. I mainly used AI when I got stuck on an error,
needed to check an implementation, or wanted to speed up small repetitive
tasks.

## Fixing TypeScript errors

I used AI when TypeScript showed errors during development.

Example prompt:

"Here is the TypeScript error I am getting. Here is the related code.
Explain why this error is happening and suggest the smallest fix without
changing the existing structure."

I checked the suggested changes and applied the ones that fit the project.

## Debugging API errors

While testing the backend, I used AI to help understand API errors and
unexpected responses.

Example prompt:

"This API request is returning this error. Here is the route, service
function and error message. Find the likely problem and tell me what I
should check."

This was mainly useful for finding small issues such as incorrect request
data, missing parameters and error handling.



## Frontend debugging

I used AI when some React components or pages were not behaving as
expected.

Example prompt:

"This React page is not updating after the API request. Here is the
component and the hook being used. Find the issue and suggest a minimal
change."

I used this mostly for debugging state updates, API calls and UI issues.

## CSS and UI improvements

AI was also used for small UI improvements and repetitive styling work.

Example prompt:

"Make this existing Tailwind layout look cleaner and more consistent
without changing the functionality or component structure."

The generated suggestions were reviewed and adjusted before being used.

## Testing and error checking

I used AI to help understand test failures and to suggest additional cases
that were worth checking.

Example prompt:

"This test is failing. Explain what the failure means and whether the
problem is in the test or the implementation."

I still checked the actual application behaviour rather than relying only
on the suggested answer.

## Documentation

AI was used to speed up some of the documentation work after the
implementation was completed.

For example, I used it to help organize notes about the project structure,
setup steps and implementation details into the required markdown files.

## General use

Overall, AI was mainly used as a debugging and productivity tool. I
provided the existing code and error messages when needed, reviewed the
suggestions, and made the final changes myself.
